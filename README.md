# Student Performance Tracker

## 1. Project Name
Student Performance Tracker

## 2. Project Description
The Student Performance Tracker is a Python-based project
that analyzes students' academic performance using their
subject marks.

It calculates total marks, average marks, and class average.
It also displays student performance using a bar chart.

## 3. Project Scope
The main objective of this project is to analyze student
performance and compare the academic results of students.

## 4. Technologies Used
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## 5. Features
- Stores student marks
- Calculates total marks
- Calculates average marks
- Calculates class average
- Displays student performance in a bar chart

## 6. Dataset
The project uses sample student marks for demonstration.

## 7. Output
The program displays a student performance report and
a bar chart comparing students' average marks.

## 8. How to Run
1. Install Python.
2. Install the required libraries.
3. Open the project folder in VS Code.
4. Run the following command:

python student_tracker.py
